Distance Vector Routing Algorithm in C — often used in network simulations to demonstrate how routers share distance vectors to calculate the shortest paths.

 Distance Vector Routing Algorithm in C
Algorithm: Distance Vector Routing
Input:
•	Number of nodes in the network, N
•	Cost matrix C[N][N] where C[i][j] is the cost to go from node i to node j

Steps:
1.	For each node i (1 ≤ i ≤ N):
o	Initialize its distance vector DV[i]:
	DV[i][j] = C[i][j] for all j
o	Set the next hop to j if there is a direct connection; otherwise, to -1
2.	Repeat the following steps until no distance vector changes:
o	For each node i:
	For each destination node j:
	For each neighbor k of node i:
	If DV[i][j] > C[i][k] + DV[k][j]:
	Update DV[i][j] = C[i][k] + DV[k][j]
	Set next hop to k
3.	After convergence, print the final distance vectors (routing tables) for all nodes

Explanation:
•	Each node exchanges its distance vector with its immediate neighbors.
•	On receiving a neighbor’s vector, it updates its own vector if it finds a shorter path.
•	This repeats until no update is needed (network converges).
C program
#include <stdio.h>

#define MAX_NODES 10
#define INF 9999

struct Node {
    int dist[MAX_NODES];
    int from[MAX_NODES];
} rt[MAX_NODES];

int main() {
    int cost[MAX_NODES][MAX_NODES], nodes, i, j, k;
    int updated, iteration;

    printf("Enter number of nodes: ");
    scanf("%d", &nodes);

    printf("Enter cost matrix row by row (use 999 for ∞/no connection):\n");
    for (i = 0; i < nodes; i++) {
        for (j = 0; j < nodes; j++) {
            int v;
            scanf("%d", &v);
            if (v == 999) cost[i][j] = INF;
            else cost[i][j] = v;
        }
    }

    for (i = 0; i < nodes; i++) {
        cost[i][i] = 0;
        for (j = 0; j < nodes; j++) {
            rt[i].dist[j] = cost[i][j];
            if (cost[i][j] < INF && i != j) rt[i].from[j] = j; // next hop is the neighbor j
            else rt[i].from[j] = -1; // unknown/unreachable
        }
    }

    /* Repeat relaxations at most nodes-1 times (Bellman-Ford style). */
    for (iteration = 0; iteration < nodes - 1; iteration++) {
        updated = 0;
        for (i = 0; i < nodes; i++) {
            for (j = 0; j < nodes; j++) {
                for (k = 0; k < nodes; k++) {
                    if (cost[i][k] >= INF) continue;         // no direct link i->k
                    if (rt[k].dist[j] >= INF) continue;     // k->j not known
                    int newdist = cost[i][k] + rt[k].dist[j];
                    if (newdist < rt[i].dist[j]) {
                        rt[i].dist[j] = newdist;
                        rt[i].from[j] = k;
                        updated = 1;
                    }
                }
            }
        }
        if (!updated) break;
    }

    // Display routing table
    for (i = 0; i < nodes; i++) {
        printf("\nRouting table for Node %d:\n", i);
        printf("Destination\tNext Hop\tDistance\n");
        for (j = 0; j < nodes; j++) {
            if (rt[i].dist[j] >= INF)
                printf("%d\t\t%s\t\t%s\n", j, (rt[i].from[j] == -1 ? "-" : "-"), "INF");
            else
                printf("%d\t\t%d\t\t%d\n", j, rt[i].from[j], rt[i].dist[j]);
        }
    }

    return 0;
}

Explanation
•	Each router (node) maintains a table with:
o	Distance to every other node
o	Next hop to reach each node
•	The algorithm loops until no updates are made, ensuring the shortest paths are computed.
